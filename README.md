# Digital E-Commerce Store 🌐🛒

Welcome to the **Digital E-Commerce Store** 🚀, a full-stack platform for buying and selling digital products such as source code files, UI kits, Figma designs, PDFs, books, and much more. Built with modern technologies, this app offers a seamless and secure shopping experience for digital goods.

You can check out the live project here: [Digital E-Commerce Store](https://digital-e-commerce-store.vercel.app/) 🔗

## Features 🎉

- **Buy and Sell Digital Products:** Browse, purchase, and sell digital products like source code files, design assets, eBooks, and more. 💻📚
- **User Authentication:** Sign up, log in, and manage accounts using [Clerk](https://clerk.dev/). 🔑
- **Payment Integration:** Secure online payments powered by [PayPal](https://www.paypal.com/). 💳
- **Image Hosting:** Store and manage images using [Firebase](https://firebase.google.com/). 🖼️
- **Modern UI:** A clean and user-friendly interface built with [TailwindCSS](https://tailwindcss.com/) and [ShadCN UI](https://github.com/shadcn/ui). 🎨
- **Real-Time Database:** All user data and transactions are stored securely using [Neon DB](https://neon.tech/), a scalable serverless database. 🗄️
